# 市场商品 300 排行榜分析与交互式可视化大屏

本项目为天猫床垫类目 Top 300 爆款商品的深度数据挖掘、价格带/排名分布分析、RapidOCR 首图卖点与营销文案全景透视交互大屏。

---

## 🌟 核心功能特性

1. **🎯 价格与排名多维交互大屏**：
   - 实时中位数、均值、SKU 丰富度与价格区间动态统计。
   - 价格带自动化归类（300元以下、300-800、800-1500、1500-2000、2000-3000、3000-5000、5000+）。
   - 排名梯队自动化归类（Top1-10、Top1-30、Top1-50、Top1-100、Top101-300）。
   - 品牌矩阵与店铺渗透率排行。

2. **🔍 四维去重搜索范围切换**：
   - 🌐 **全域去重综合**：主图文案 + 标题 + 店铺 + 1.8m SKU 规格全量去重综合检索。
   - 🎯 **仅主图内容/卖点**：专门挖掘首图宣传、但在标题中省略的高转化核心卖点。
   - 📝 **仅商品标题/店铺**：仅针对天猫上架标题和店铺名。
   - 🏷️ **仅SKU规格**：针对 1.8 米具体 SKU 的细分睡感、厚度与版本名称。

3. **🖼️ 首图视觉与引流定价透视（RapidOCR 全量提取）**：
   - 全网 300 款商品首图 OCR 全量文案识别与结构化分类（卖点/权益/视觉形式）。
   - **主图展示价 vs 1.8m SKU 最低/中位价偏差分析**与**低价引流度指数**（🔥深度补贴 / 🎯精准对标 / ✨中位走量 / 💎高配旗舰）。
   - 44 款明示标价商品深度对标大表与全景卡片流检索器。

4. **⚖️ 多组多维度横向对比分析矩阵**：
   - 支持自定义 A/B/C/D/E 任意多组对比。
   - 每组可独立设置价格区间、排名范围、床垫厚度、关键词及搜索维度。
   - 一键横向对比价格中位数、均价、排名中位数、厚度分布与单品 SKU 丰富度。

## 📂 项目文件清单

- `床垫300款排名与SKU价格交互分析大屏.html`：**单文件独立交互大屏**，内嵌全部 300 款商品与 4594 条 SKU 数据及首图 OCR 分析，直接双击在任何现代浏览器中即可离线运行。
- `main_images_full_analysis.json`：全量 300 款商品的 RapidOCR 原始文案、功能卖点、营销文案、视觉格式与定价引流度结构化数据库。
- `一键同步到GitHub.bat`：Windows 下双击自动 `git add`, `commit` 并 `push` 到 GitHub 的快捷脚本。

直接双击打开 `床垫300款排名与SKU价格交互分析大屏.html` 即可使用，无需启动本地 Node.js 或 Web 服务器。
